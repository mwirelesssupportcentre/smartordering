Send or collect orders (works without sign-in)

Managers: pick your store, enter quantities, then press "Get my order code" and send that code to the admin (WhatsApp, email, anything).

Admin: paste all codes you received (one per line) and press Import. Then press "Download Excel (all stores)".

Store setup (store names and IASR names)

Add each store with the name you want to see in this portal and the name exactly as it appears in the IASR file (the Location column). When the IASR file is uploaded, its rows are matched to your stores by these IASR names (capitals and extra spaces do not matter). If you leave the IASR name blank, the store name is used. To match more than one IASR name to a store, separate them with a semicolon. Stores that share a Pool name share one budget. After adding new stores, set their budgets under "Edit monthly budget".
